### Verify another way

Scammers can make calls look like they come from a bank, government office, or local number. Caller ID is not enough.

- Hang up if the call creates pressure.
- Call back using a number you already trust.
- Never use the number the caller gives you.

The call checker helps users notice spoofing patterns.
