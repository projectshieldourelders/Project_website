### The code is the key

Scammers often say they need a code to verify you. In reality, that code may let them sign in to your account.

- Hang up if someone asks for a code.
- Call the official number on your card or statement.
- Do not trust caller ID by itself.

Shield Our Elders flags code requests as a serious warning sign.
